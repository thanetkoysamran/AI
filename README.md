เปิด `AI_index.html` ในเว็บเบราว์เซอร์
ตรวจสอบว่าเบราว์เซอร์โหลดไลบรารีภายนอกได้
ดูข้อมูลเริ่มต้นใน Overview หรือเลือกแท็บหน่วยงาน
หากต้องการเปลี่ยนข้อมูล ให้เลือกแท็บ Update แล้วเลือกไฟล์ Excel สำหรับ AiPASS หรือ AI
บันทึก HTML หลังนำเข้าข้อมูล หากต้องการเก็บข้อมูลใหม่ไว้ในไฟล์
เอกสารนี้จัดทำจากการอ่านโค้ด ยังไม่ได้ทดสอบการทำงานในเบราว์เซอร์จริง
การนำเข้า Excel
`readSheet()` อ่านไฟล์ด้วย `XLSX.read()` และเลือกชีตที่แถวแรกมีหัวคอลัมน์ขึ้นต้นตรงกับข้อความที่โค้ดกำหนด จากนั้นส่งข้อมูลให้ `parseCert()` หรือ `parseAi()`
แถวแรกของชีตต้องเป็นหัวคอลัมน์ที่ parser รองรับ
การนำเข้า AiPASS ใช้ข้อมูลเวลา อีเมล บัญชี หน่วยงาน หน่วยย่อย ชื่อบุคลากร และค่า AiPASS
การนำเข้า AI ใช้ประเภท ระยะ/ขั้นตอน หน่วยงาน ชื่อสื่อ สถานะ ชื่อโครงการ จำนวนสมาชิก และวันเริ่มต้น
เมื่ออ่านข้อมูลสำเร็จ โค้ดอัปเดต state เรียก `render()` และแสดงสถานะว่ามีข้อมูลเปลี่ยนแปลง
เมื่อเกิดข้อผิดพลาด ข้อความจะแสดงในองค์ประกอบ `status`
ข้อจำกัดในการตรวจสอบ: ข้อความภาษาไทยบางส่วนในเนื้อหาที่เครื่องมืออ่านได้ปรากฏเป็นช่องว่าง จึงยังระบุชื่อหัวคอลัมน์ Excel แบบตรงตัวไม่ได้ ควรตรวจสอบ string ใน `parseCert()`, `parseAi()` และ `wireUpload()` จากไฟล์ต้นฉบับก่อนจัดทำแม่แบบ Excel
โครงสร้างข้อมูลภายใน
ข้อมูลเริ่มต้นอยู่ใน JSON ขององค์ประกอบ `aipass-data` และโหลดเข้าสู่ `BOOT`
AiPASS
```javascript
[id, isoTime, email, account, dept, section, thaiField, sat, cert]
```
สื่อและโครงการ AI
```javascript
[id, isoTime, email, account, type, stage, dept,
 mediaName, status, person, project, members, start]
```
โครงสร้างเหล่านี้เป็นข้อมูลภายในหลังแปลงแล้ว ไม่ใช่ชื่อหัวคอลัมน์ของ Excel
จุดสำคัญในโค้ด
ส่วน	หน้าที่
`BOOT`	ข้อมูลเริ่มต้นที่อ่านจาก JSON
`IMG` / `aipass-img`	ภาพที่ฝังอยู่ในไฟล์
`DEPTS` / `DEPT_ORDER`	กำหนดหน่วยงาน PD, MT, EC, HSE
`state`	ข้อมูลและสถานะการแสดงผลปัจจุบัน
`build()` / `buildAi()`	แปลงข้อมูลเป็นโครงสร้างสำหรับแสดงผล
`load()` / `loadAi()`	อัปเดตข้อมูลใน state
`render()` / `renderPeople()`	แสดงข้อมูลบนหน้าเว็บ
`showTab()`	เปลี่ยนแท็บและจดจำแท็บล่าสุด
`readSheet()`	อ่านข้อมูล Excel
`parseCert()` / `parseAi()`	แปลงแถว Excel
`wireUpload()`	เชื่อมปุ่มและ input สำหรับนำเข้า
`pageHtml()`	สร้าง HTML จาก template และข้อมูลปัจจุบัน
`makePdf()`	สร้าง PDF
`makeHtml()` / `saveHtmlFile()`	ส่งออกหรือบันทึก HTML
`saveToPage()`	เรียก API ของสภาพแวดล้อมโฮสต์เพื่อเผยแพร่หน้า
`boot()`	โหลดข้อมูลเริ่มต้นและแสดงหน้าเว็บ
การบันทึกและส่งออก
HTML
`pageHtml()` สร้างหน้าใหม่จาก template ใน `aipass-tpl` พร้อมข้อมูลใน state และภาพที่ฝังอยู่ ไม่ได้คัดลอก live DOM โดยตรง
`saveHtmlFile()` ใช้ `showSaveFilePicker()` เมื่ออยู่ในหน้าต่างหลักและ API พร้อมใช้งาน หากไม่พร้อมหรือบันทึกไม่ได้ โค้ดใช้เส้นทางดาวน์โหลดไฟล์แทน
PDF
`makePdf()` ใช้ html2canvas จับภาพ `.wrap` แล้วแบ่งภาพลงใน PDF A4 แนวตั้งด้วย jsPDF พร้อมเลขหน้า ข้อความในส่วนที่จับภาพจึงเป็นภาพ ไม่ใช่ข้อความ PDF ที่สร้างโดยตรง
การเผยแพร่กลับหน้าเดิม
`saveToPage()` พึ่งพา `window.claude.use("artifact")` และ `art.publish()` ซึ่งเป็น API เฉพาะสภาพแวดล้อม ไม่ควรคาดหวังว่าจะใช้งานได้เมื่อเปิดไฟล์ HTML ทั่วไป หากไม่มีสิทธิ์หรือ API ไม่พร้อม ให้ใช้การบันทึก HTML
การพิมพ์
โค้ดแสดงปุ่มพิมพ์เมื่อ `window.self === window.top` และเรียก `window.print()`
การจดจำสถานะ
`localStorage` เก็บชื่อแท็บล่าสุดด้วย key `aipass-tab` ส่วนข้อมูลที่นำเข้าเก็บใน state ระหว่างใช้งานและถูกฝังกลับใน HTML เมื่อบันทึก ไม่ควรเข้าใจว่าการนำเข้าข้อมูลอย่างเดียวเป็นการบันทึกไฟล์ถาวรแล้ว
ข้อควรระวังและแนวทางแก้ปัญหา
ข้อแนะนำต่อไปนี้เป็นแนวทางตรวจสอบ ไม่ใช่ผลการทดสอบ:
หากนำเข้า Excel ไม่ได้ ให้ตรวจสอบการโหลด XLSX และหัวคอลัมน์ในแถวแรก
หากสร้าง PDF ไม่ได้ ให้ตรวจสอบการโหลด html2canvas และ jsPDF
หากเปิดไฟล์ใหม่แล้วไม่พบข้อมูลที่เพิ่งนำเข้า ให้ตรวจสอบว่าได้บันทึกและเปิด HTML ฉบับใหม่แล้ว
หากบันทึกกลับหน้าเผยแพร่ไม่ได้ ให้ใช้ Save HTML แทน
หากแก้ไขหน้าเว็บ ควรตรวจสอบ template ใน `aipass-tpl` ด้วย เพราะการส่งออกใช้ template นี้
ไฟล์ HTML ที่บันทึกฝังข้อมูลไว้ภายใน ควรตรวจสอบข้อมูลบุคลากรและสิทธิ์การเผยแพร่ก่อนแชร์
สถานะเอกสาร
